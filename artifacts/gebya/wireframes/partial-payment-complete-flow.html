FIXED: payment_type="telebirr", payment_provider="telebirr" → reportSelectors.js: isTransferPayment() returns true → Report: Transfer Recorded = 300 ✅
How isTransferPayment() works (reportSelectors.js):
const payment = String(row?.payment_type || row?.payment_method || '').toLowerCase();
const provider = String(row?.payment_provider || '').toLowerCase();
return ['bank', 'transfer', 'mobile', 'telebirr', 'cbe', 'mpesa'].some(key => payment.includes(key) || provider.includes(key));
When payment_type = "telebirr" → matches "telebirr" in the list → returns true → categorized as TRANSFER ✅
