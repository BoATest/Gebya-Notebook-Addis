🔑 The Code Change — 1 Line in TransactionForm.jsx

Current (broken) line 216:

payment_provider: (!isCredit && !isCreditSale && !isPartialSale && paymentType !== 'cash') ? paymentProvider || null : null,

Fixed line (remove the !isPartialSale check):

payment_provider: (!isCredit && !isCreditSale) ? (paymentType !== 'cash' ? paymentProvider || null : null) : null,

Why this works: The current code has && !isPartialSale which means "skip the payment provider for partial sales." Removing this allows partial sales to use whatever payment chip is selected (telebirr, CBE, etc). The report system in reportSelectors.js already handles this correctly because it checks payment_type and payment_provider to determine if something is cash or transfer.

The key insight: The chips are already there. We just remove the !isPartialSale exclusion so the selected chip's value is actually saved for partial sales too.
